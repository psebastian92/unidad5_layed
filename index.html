01

Ordenamiento burbuja

El algoritmo de burbuja recorre el array comparando dos elementos adyacentes. Si están en el orden incorrecto, los intercambia. Repite este proceso hasta que no haya ningún intercambio — eso significa que el array quedó ordenado.

El nombre viene de que los valores más grandes "burbujean" hacia el final del array en cada pasada.

Código completo
Array int[]
static void ordenarBurbuja(int[] nums) {
    int n = nums.length;
    for (int i = 0; i < n-1; i++) {
        for (int j = 0; j < n-i-1; j++) {
            if (nums[j] > nums[j+1]) {
                int aux  = nums[j];
                nums[j]   = nums[j+1];
                nums[j+1] = aux;
            }
        }
    }
}

// Uso en main():
int[] nums = {5,3,8,1,4};
ordenarBurbuja(nums);
// nums → [1, 3, 4, 5, 8]
ArrayList<Integer>
static void ordenarBurbuja(
        ArrayList<Integer> nums) {
    int n = nums.size();
    for (int i = 0; i < n-1; i++) {
        for (int j = 0; j < n-i-1; j++) {
            if (nums.get(j) > nums.get(j+1)) {
                int aux = nums.get(j);
                nums.set(j,   nums.get(j+1));
                nums.set(j+1, aux);
            }
        }
    }
}

// Uso en main():
ArrayList<Integer> nums = new ArrayList<>();
nums.add(5); nums.add(3); nums.add(8);
ordenarBurbuja(nums);
// nums → [1, 3, 4, 5, 8]
¿Por qué n - i - 1 en el for interno?

Después de cada pasada, el elemento más grande ya está en su lugar al final. No hace falta compararlo de nuevo. n - i - 1 reduce el rango en cada pasada y ahorra comparaciones innecesarias.

⚠ Errores frecuentes
✗No usar variable auxiliar al intercambiar: numeros[j] = numeros[j+1]; numeros[j+1] = numeros[j]; — esto sobreescribe el valor antes de guardarlo. Siempre necesitás int aux.
✗Poner j < n en el for interno en lugar de j < n - i - 1 — causa ArrayIndexOutOfBoundsException porque intentás acceder a numeros[n] que no existe.

02

Ordenamiento por inserción

El algoritmo de inserción funciona como cuando ordenás cartas en la mano: tomás una carta y la insertás en el lugar correcto entre las que ya tenés ordenadas.

En cada iteración, tomás el elemento actual y lo comparás hacia la izquierda, moviendo los elementos mayores una posición a la derecha, hasta encontrar su lugar correcto.

Código completo
Array int[]
static void ordenarInsercion(int[] nums) {
    for (int i = 1; i < nums.length; i++) {
        int actual = nums[i];
        int j = i - 1;
        while (j >= 0 && nums[j] > actual) {
            nums[j+1] = nums[j];
            j--;
        }
        nums[j+1] = actual;
    }
}

// Uso en main():
int[] nums = {5,3,8,1,4};
ordenarInsercion(nums);
// nums → [1, 3, 4, 5, 8]
ArrayList<Integer>
static void ordenarInsercion(
        ArrayList<Integer> nums) {
    for (int i = 1; i < nums.size(); i++) {
        int actual = nums.get(i);
        int j = i - 1;
        while (j >= 0 &&
               nums.get(j) > actual) {
            nums.set(j+1, nums.get(j));
            j--;
        }
        nums.set(j+1, actual);
    }
}

// Uso en main():
ArrayList<Integer> nums = new ArrayList<>();
nums.add(5); nums.add(3); nums.add(8);
ordenarInsercion(nums);
// nums → [1, 3, 4, 5, 8]
¿Por qué empieza en i = 1?

El primer elemento (i = 0) ya está "ordenado" por sí solo. No hay nada a su izquierda con qué compararlo. El algoritmo arranca desde el segundo elemento.

⚠ Errores frecuentes
✗Olvidar guardar actual = numeros[i] antes del while — si no, sobrescribís el valor y lo perdés para siempre.
✗No chequear j >= 0 en el while — cuando j llega a -1, accedés a numeros[-1] y obtenés excepción.
Ejemplo con listas paralelas

Cuando ordenás listas paralelas (por ejemplo nombres y notas), cada vez que movés un elemento en una lista tenés que moverlo también en la otra para mantenerlas sincronizadas.

JAVAInserción sobre listas paralelas — nombres y notas (mayor a menor)
static void ordenarPorNota(
        ArrayList<String> nombres,
        ArrayList<Integer> notas) {

    for (int i = 1; i < notas.size(); i++) {
        int    notaActual   = notas.get(i);
        String nombreActual = nombres.get(i);
        int j = i - 1;

        // Mayor a menor: movemos cuando la nota de la izq es MENOR
        while (j >= 0 && notas.get(j) < notaActual) {
            notas.set(j + 1,   notas.get(j));    // mover nota
            nombres.set(j + 1, nombres.get(j));  // mover nombre (mismo índice)
            j--;
        }
        notas.set(j + 1,   notaActual);    // insertar nota en su lugar
        nombres.set(j + 1, nombreActual);  // insertar nombre en su lugar
    }
}

// Uso en main():
ArrayList<String>  nombres = new ArrayList<>();
ArrayList<Integer> notas   = new ArrayList<>();
nombres.add("Ana");   notas.add(7);
nombres.add("Luis");  notas.add(9);
nombres.add("Sol");   notas.add(6);
ordenarPorNota(nombres, notas);
// nombres → [Luis, Ana, Sol]
// notas   → [9,    7,   6  ]
Clave: las dos listas se mueven juntas

Cuando usás set(j+1, get(j)) en notas, hacés lo mismo en nombres en el mismo paso. Si te olvidás de mover una, los nombres y notas quedan desincronizados — Ana podría terminar con la nota de Luis.

Comparación de métodos

Ambos algoritmos ordenan correctamente, pero tienen comportamientos distintos. La diferencia clave está en cuántos movimientos hacen.

Característica Burbuja Inserción sort()
¿Cómo funciona? Compara pares adyacentes y los intercambia Toma un elemento y lo inserta donde corresponde Algoritmo optimizado interno de Java
Tiempo real (1.000 elementos) ~5 ms ~1 ms < 0.1 ms
Array casi ordenado Sigue recorriendo todo igual Muy eficiente — casi no hace nada Muy eficiente
¿Sirve con listas paralelas? Sí, con cuidado Sí — lo usamos en el desafío 30 No directamente
¿Se usa en producción? No — solo pedagógico En casos específicos Sí — es el método recomendado
El método sort() de Java

Cuando no trabajás con listas paralelas, Java ya tiene un método optimizado que ordena en una línea:

JAVAOrdenar con sort() — la forma recomendada en producción
import java.util.Arrays;
import java.util.Collections;

// Array de enteros
int[] numeros = {5, 3, 8, 1, 4};
Arrays.sort(numeros);                          // [1, 3, 4, 5, 8]

// ArrayList de Strings
ArrayList<String> nombres = new ArrayList<>();
Collections.sort(nombres);                     // orden alfabético

// ArrayList de Integer
ArrayList<Integer> notas = new ArrayList<>();
Collections.sort(notas);                       // de menor a mayor
Collections.sort(notas, Collections.reverseOrder()); // de mayor a menor
⚠ ¿Por qué aprender burbuja e inserción si existe sort()?

Porque sort() es una caja negra — no sabés qué hay adentro. Aprender burbuja e inserción te enseña a pensar algorítmicamente: cómo se compara, cómo se intercambia, qué tan costoso es cada paso. Además, cuando tenés listas paralelas (nombres + notas), sort() no sirve directamente — necesitás controlar vos el intercambio para mantener la sincronización.

📊 Sobre los tiempos que van a medir

Con 8 elementos, los tiempos van a ser muy pequeños (nanosegundos) y puede parecer que son iguales o que burbuja es más rápido. La diferencia real se nota con miles o millones de elementos. El ejercicio sirve para aprender a medir — la diferencia conceptual la discutimos en clase.

04

Medir tiempo de ejecución

Java tiene System.nanoTime() que devuelve el tiempo actual en nanosegundos. Si lo llamás antes y después del algoritmo, la diferencia es el tiempo que tardó en ejecutarse.

JAVAPatrón para medir cualquier algoritmo
long inicio = System.nanoTime();

miAlgoritmo(datos);  // lo que querés medir

long fin = System.nanoTime();
long tiempoNs = fin - inicio;

System.out.println("Tiempo: " + tiempoNs + " ns");
System.out.println("Tiempo: " + tiempoNs / 1_000_000.0 + " ms");
Importante: copiar el array antes de medir

Si ordenás el array con burbuja y después lo medís con inserción, el segundo ya recibe un array ordenado — lo cual hace trampa en la comparación. Copiá el array original antes de cada medición con Arrays.copyOf(original, original.length).

JAVAComparar ambos algoritmos correctamente
import java.util.Arrays;

int[] original = {5, 3, 8, 1, 4, 7, 2, 6};

// Copias independientes para cada algoritmo
int[] copia1 = Arrays.copyOf(original, original.length);
int[] copia2 = Arrays.copyOf(original, original.length);

long tiempoBurbuja   = medirBurbuja(copia1);
long tiempoInsercion = medirInsercion(copia2);

System.out.println("Burbuja:   " + tiempoBurbuja   + " ns");
System.out.println("Inserción: " + tiempoInsercion + " ns");
05

Búsqueda lineal

La búsqueda lineal recorre el array elemento por elemento desde el principio hasta encontrar el valor buscado, o hasta llegar al final sin encontrarlo.

Es el método más simple y funciona con cualquier array — ordenado o no. Retorna la posición del elemento, o -1 si no lo encontró (igual que indexOf() en las listas).

Código completo
Array int[]
static int busquedaLineal(
        int[] nums, int objetivo) {
    for (int i = 0; i < nums.length; i++) {
        if (nums[i] == objetivo) {
            return i;
        }
    }
    return -1;
}

static void mostrarResultado(
        int pos, int objetivo) {
    if (pos != -1)
        System.out.println("Posición: " + pos);
    else
        System.out.println("No encontrado");
}

// Uso en main():
int[] nums = {3,1,8,4,7};
int pos = busquedaLineal(nums, 4);
// pos → 3
ArrayList<Integer>
static int busquedaLineal(
        ArrayList<Integer> nums,
        int objetivo) {
    for (int i = 0; i < nums.size(); i++) {
        if (nums.get(i) == objetivo) {
            return i;
        }
    }
    return -1;
}

// O simplemente con indexOf():
int pos = nums.indexOf(objetivo);
// hace exactamente lo mismo ↑

// Uso en main():
ArrayList<Integer> nums = new ArrayList<>();
nums.add(3); nums.add(1); nums.add(8);
int pos = busquedaLineal(nums, 8);
// pos → 2
Conexión con indexOf()

Lo que hacen busquedaLineal() e indexOf() es exactamente lo mismo: recorrer, comparar, retornar la posición o -1. La diferencia es que nosotros lo programamos a mano para entender cómo funciona por dentro.

Ejemplo con listas paralelas

Con listas paralelas, buscás por nombre usando indexOf() y con esa posición accedés directamente a la nota — sin recorrer la segunda lista.

JAVABúsqueda lineal sobre listas paralelas — buscar alumno por nombre
static void buscarAlumno(
        ArrayList<String>  nombres,
        ArrayList<Integer> notas) {

    System.out.print("Nombre a buscar: ");
    String nombre = sc.nextLine();

    int pos = nombres.indexOf(nombre);  // búsqueda lineal

    if (pos != -1) {
        System.out.println(nombre + " → nota: " + notas.get(pos));
    } else {
        System.out.println("No se encontró ese alumno.");
    }
}

// Uso en main():
// nombres: [Luis, Ana, Sol]
// notas:   [9,    7,   6  ]
buscarAlumno(nombres, notas);
// Usuario escribe "Ana"
// pos = indexOf("Ana") → 1
// notas.get(1) → 7
// salida: "Ana → nota: 7"
indexOf() hace la búsqueda lineal por vos

No necesitás escribir el for — indexOf() lo hace internamente. Lo que sí necesitás es usar esa posición para acceder a la otra lista con notas.get(pos). La posición es el puente entre las dos listas.

Búsqueda binaria

La búsqueda binaria es mucho más eficiente que la lineal, pero tiene un requisito fundamental: el array debe estar ordenado.

En lugar de recorrer elemento por elemento, mira el elemento del medio y decide si el objetivo está en la mitad izquierda o en la derecha. En cada paso descarta la mitad del array que no puede contener el objetivo.

Código completo
Array int[]
static int busquedaBinaria(
        int[] nums, int objetivo) {
    int inicio = 0;
    int fin    = nums.length - 1;
    while (inicio <= fin) {
        int medio = (inicio + fin) / 2;
        if (nums[medio] == objetivo)
            return medio;
        else if (nums[medio] < objetivo)
            inicio = medio + 1;
        else
            fin = medio - 1;
    }
    return -1;
}

// Uso en main():
// ⚠ array debe estar ordenado
int[] nums = {1,3,4,5,7,8,9};
int pos = busquedaBinaria(nums, 7);
// pos → 4
ArrayList<Integer>
static int busquedaBinaria(
        ArrayList<Integer> nums,
        int objetivo) {
    int inicio = 0;
    int fin    = nums.size() - 1;
    while (inicio <= fin) {
        int medio = (inicio + fin) / 2;
        if (nums.get(medio) == objetivo)
            return medio;
        else if (nums.get(medio) < objetivo)
            inicio = medio + 1;
        else
            fin = medio - 1;
    }
    return -1;
}

// Uso en main():
// ⚠ lista debe estar ordenada
ArrayList<Integer> nums = new ArrayList<>();
// (cargar y ordenar antes)
int pos = busquedaBinaria(nums, 7);
// pos → índice del 7
⚠ Error crítico
✗Usar búsqueda binaria sobre un array no ordenado — el algoritmo va a dar resultados incorrectos sin dar error. Siempre ordenar antes con inserción o burbuja.
✗Olvidar actualizar inicio o fin — el while quedaría infinito.
Ejemplo con listas paralelas

La binaria sobre listas paralelas requiere que las listas estén ordenadas por el campo que buscás. Una vez ordenadas, la búsqueda es muy eficiente.

JAVABúsqueda binaria sobre listas paralelas — buscar por nota
static int buscarPorNota(
        ArrayList<Integer> notas,
        int objetivo) {
    // Requiere lista de notas ordenada de menor a mayor
    int inicio = 0;
    int fin    = notas.size() - 1;
    while (inicio <= fin) {
        int medio = (inicio + fin) / 2;
        if (notas.get(medio) == objetivo)
            return medio;         // retorna la posición
        else if (notas.get(medio) < objetivo)
            inicio = medio + 1;
        else
            fin = medio - 1;
    }
    return -1;
}

// Uso en main():
// (listas ya ordenadas de menor a mayor)
// nombres: [Sol,  Ana, Luis]
// notas:   [6,    7,   9   ]
int pos = buscarPorNota(notas, 7);
// pos → 1
// nombres.get(1) → "Ana"
System.out.println("Nota 7: " + nombres.get(pos));
Orden de la lista importa

Si ordenaste de mayor a menor con inserción (desafío 30), la binaria necesita el orden inverso. En ese caso cambiá la condicion < por > en el while. Siempre verificá el orden antes de aplicar búsqueda binaria.
